1. Add Vendor

Route

POST /vendor/addvendor

Description

Creates a new vendor with associated products in the system.

Request Body

{ "STOKEN": "your_session_token_here", "querystring": "encrypted_data_containing_vendor_details" }

Decrypted Querystring Data

{ "vendorname": "JK constructiond", "vendormailid": "jk@gmail.com", "vendorphoneno": "8393923242", "vendoraddress": "chinnverampatti,udumallai", "vendorgst": "33ABCD43wsd123", "vendorproducts": [ { "productname": "Cement", "gstpercent": 18.0, "hsn": "2523", "price": 350.00 }, { "productname": "Steel", "gstpercent": 18.0, "hsn": "7207", "price": 600.00 } ] }

Response Body

Success Response

{ "code": true, "message": "Vendor Added Successfully", "Value": 13 }

Error Response

{ "code": false, "message": "Error message describing the issue", "Value": "ADD VENDOR" }

Required Fields

  • vendorname: Vendor company name
  • vendormailid: Vendor email address
  • vendorphoneno: Vendor phone number
  • vendoraddress: Vendor business address
  • vendorgst: Vendor GST number
  • vendorproducts: Array of products (optional)

3. Add Quotation

Route

POST /vendor/addquotation

Description

Uploads a vendor quotation PDF file and associates it with an RFQ ID.

Request Body

  • Content-Type: multipart/form-data
  • File Field: file (PDF file, max 5MB)
  • Form Fields:
    • STOKEN: Session token
    • querystring: Encrypted data containing RFQ details

Decrypted Querystring Data

{ "rfqid": "SSIPL-RFQ/2507/01" }

Response Body

Success Response

{ "code": true, "message": "Quotation Added Successfully", "Value": 1 }

Error Response

{ "code": false, "message": "Error message describing the issue", "Value": "ADD QUOTATION" }

File Requirements

  • Format: PDF only
  • Size: Maximum 5MB
  • Storage: Saved in /filestorage/YYYY/Month/DD/VendorQuotation/

4. Vendor Details Preloader (RFQ ID Generator)

Route

POST /vendor/detailspreloader

Description

Generates a unique RFQ ID for creating new RFQ processes.

Request Body

{ "STOKEN": "your_session_token_here" }

Response Body

Success Response

{ "code": true, "message": "RFQ ID generated successfully", "rfq_id": "SSIPL-RFQ/2507/01" }

Error Response

{ "code": false, "message": "Error message describing the issue", "rfq_id": null }

RFQ ID Format

  • Pattern: SSIPL-RFQ/{YYMM}/{counter}
  • YYMM: Year-Month (e.g., 2507 for July 2025)
  • Counter: 2-digit sequential number (01, 02, etc.)
  • Generated By: Gen_vendor_rfqId stored procedure
  • Storage: vendor_rfq_ids table

6. Get Sub Process List

Route

POST /vendor/getsubprocesslist

Description

Retrieves subprocess records from vprocesslist table where vprocess_id equals the provided process ID. This API is used to fetch all related subprocess activities for a specific parent process.

Request Body

{ "STOKEN": "your_session_token_here", "querystring": "encrypted_data_containing_process_id" }

Decrypted Querystring Data

{ "vprocess_id": 1 }
Note: vprocess_id is required - this is the parent process ID to fetch subprocess list for.

Response Body

Success Response

{ "code": true, "message": "Sub process list fetched successfully", "Value": [ { "process_id": 1, "process_name": "RFQ", "Process_filepath": "/filestorage/2025/July/04/PostRFQ/1720098765_RFQ_Document.pdf", "Process_date": "2025-07-04", "Approved_status": 0, "status": 1, "deleted_flag": 0, "Created_by": 4, "vprocess_gen_id": "SSIPL-RFQ/2507/01", "process_type": "RFQ", "vendor_address": "chinnverampatti,udumallai", "vendor_name": "JK constructiond", "Row_updated_date": "2025-07-04 15:50:53" }, { "process_id": 2, "process_name": "QUOTATION", "Process_filepath": "/filestorage/2025/July/04/VendorQuotation/1720098890_Quote.pdf", "Process_date": "2025-07-04", "Approved_status": 0, "status": 1, "deleted_flag": 0, "Created_by": 5, "vprocess_gen_id": "SSIPL-RFQ/2507/01", "process_type": "QUOTATION", "vendor_address": "chinnverampatti,udumallai", "vendor_name": "JK constructiond", "Row_updated_date": "2025-07-04 16:20:15" } ] }

Error Response

{ "code": false, "message": "Error message describing the issue", "Value": "GET SUB PROCESS LIST" }

Required Fields

  • vprocess_id: Parent process ID (required) - must be a valid process ID from vendorprocessmaster table

Response Fields Description

  • process_id: Unique subprocess ID
  • process_name: Type of subprocess (RFQ, QUOTATION, etc.)
  • Process_filepath: Full path to uploaded document/file
  • Process_date: Date when subprocess was created
  • Approved_status: Approval status (0 = pending, 1 = approved)
  • status: Active status (1 = active, 0 = inactive)
  • process_type: Category of process (RFQ, QUOTATION, etc.)
  • vendor_address: Associated vendor address
  • vendor_name: Associated vendor name
  • vprocess_gen_id: RFQ ID linking to parent process

Common Use Cases

  • RFQ Tracking: View all documents and activities under a specific RFQ
  • Process Drilling: Navigate from main process to detailed subprocess activities
  • Document Management: See all files and documents related to a process
  • Audit Trail: Chronological view of all subprocess activities
  • Status Monitoring: Track progress of individual subprocess items

7. Post RFQ

Route

POST /vendor/postrfq

Description

Posts an RFQ to a vendor including PDF upload, database storage, and email notification.

Request Body

  • Content-Type: multipart/form-data
  • File Field: file (PDF file, max 10MB)
  • Form Fields:
    • STOKEN: Session token
    • querystring: Encrypted data containing RFQ details

Decrypted Querystring Data

{ "rfq_id": "SSIPL-RFQ/2507/01", "vendor_id": 1, "vendor_email": "vendor@example.com", "cc_email": "cc@example.com", "notes": "Please review the attached RFQ document and provide your best quotation." }

Response Body

Success Response

{ "code": true, "message": "RFQ Posted Successfully", "Value": { "vprocess_id": 1, "process_id": 2, "vendor_name": "JK constructiond", "rfq_id": "SSIPL-RFQ/2507/01" } }

Error Response

{ "code": false, "message": "Error message describing the issue", "Value": "POST RFQ" }

Process Flow

  1. File Upload: PDF saved to /filestorage/YYYY/Month/DD/PostRFQ/
  2. Database Storage:
    • Creates record in vendorprocessmaster
    • Creates record in vprocesslist
  3. Email Notification:
    • Sends RFQ email to vendor using VENDORRFQ template
    • Includes PDF attachment
    • Uses module tag VENDORRFQ for email settings

Required Fields

  • rfq_id: Valid RFQ ID (generated from preloader)
  • vendor_id: Valid vendor ID
  • vendor_email: Vendor email address (currently hardcoded to kishorekkumar34@gmail.com)
  • cc_email: CC email address (optional)
  • notes: Additional notes (optional)

File Requirements

  • Format: PDF recommended
  • Size: Maximum 10MB
  • Storage: /filestorage/YYYY/Month/DD/PostRFQ/

9. Authentication

All endpoints require a valid session token (STOKEN) that:

  • Must be between 30-50 characters in length
  • Is validated against the database using SP_STOKEN_CHECK stored procedure
  • First 16 characters are used as encryption key for querystring data

10. Security

  • All sensitive data in querystring is encrypted using AES encryption
  • Session tokens are validated on every request
  • File uploads are restricted by size and type
  • SQL injection protection through parameterized queries

11. Error Handling

Common error scenarios:

  • Invalid or missing session token
  • Malformed or invalid querystring data
  • Missing required fields
  • File upload failures
  • Database connection issues
  • Vendor not found or inactive
